**项目名称**：宠物之家 · 弹幕版（pet-home，纯前端项目）

**项目简介**：一个宠物主题的单页展示网站，以"弹幕留言"为特色交互，包含萌宠展示、访客统计与可持久化的留言板；纯前端实现，无需后端与构建工具，直接用浏览器打开即可运行。

**技术栈**：HTML5 · CSS3 · 原生 JavaScript · localStorage（数据持久化）· CSS 响应式媒体查询（800px / 480px 断点）· 暗色 / 亮色主题切换

**核心功能 / 个人职责**：
- 萌宠展示区：猫 / 狗 / 兔 / 仓鼠四类卡片，点击图片放大示意。【待补充：图片素材来源与本人是否参与拍摄 / 整理】
- 访客计数器：基于 localStorage 记录访问次数，数据保存在用户本地浏览器。
- 弹幕留言板：用户留言以弹幕形式滚动展示，刷新页面后不消失（localStorage 持久化）。
- 主题切换：暗色 / 亮色模式一键切换，偏好写入 localStorage 长期保存。
- 响应式布局：针对 800px、480px 断点适配移动端，弹幕字号随屏幕尺寸调整。【待补充：本人负责的具体模块】
- 仓库共 5 次提交，最近一次为"add pets' photos"（宠物照片补充）。【待补充：本人提交占比】

**项目亮点 / 成果**：
- 纯静态零依赖：单一 `index.html` + 样式脚本内联，无框架、无构建、无后端，双击即可运行，部署成本极低。
- 以原生 JS 实现弹幕滚动、留言持久化、访客计数与主题记忆等交互，体验完整且不依赖任何第三方服务。
- 适配桌面与移动端，交互细节（弹幕字号、断点栅格）随屏幕尺寸自动调整。
- 量化成果【待补充】：页面访问量、留言条数、用户反馈等（仓库无统计数据，请勿虚填）。
